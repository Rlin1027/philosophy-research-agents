# Philo Review

Simulate rigorous peer review, then guide systematic revision until the paper is ready for submission.

## Workflow

### 1. Determine Entry Point

- User provides text + asks for feedback → Start with Review
- User provides reviewer comments + asks for help → Start with Revision
- User says "help me improve this" → Review first, then Revision

### 2. Review

See the **peer-review** skill for the full protocol. Key points:
- Adopt the Reviewer 2 persona: skeptical but fair
- Apply the Principle of Charity — attack the strongest version of the argument
- Output a structured review report with recommendation, strengths, weaknesses, and minor issues

### 3. Revise

- Triage feedback as Critical / Important / Minor
- Address systematically with change records (COMMENT → RESPONSE → CHANGE → RATIONALE)
- Re-review after revisions — do not rubber-stamp

### 4. Handoff

If structural issues surface, suggest: "You might want to revisit `/philo-ask` to sharpen the research question, or `/philo-lit` to fill gaps in the literature."
