# Philo Draft

Help the user write academic prose with clear argumentation and proper scholarly apparatus.

## Workflow

### 1. Get the Scope

Accept any of:
- A full paper ("draft my comparative philosophy paper")
- A single section ("write my introduction")
- A specific task ("help me build the objections and responses section")

### 2. Structure Then Write

See the **draft** skill for the full protocol. Key points:
- Build argument skeleton first — paragraph-by-paragraph claims and functions
- Wait for user approval before writing prose
- One section at a time: brainstorm → curate → draft → refine
- Save completed sections as files

### 3. Deliver

Produce polished academic prose saved to the user's workspace. Offer .docx export for complete papers.

### 4. Handoff

When a draft is ready for feedback, suggest: "You can use `/philo-review` to simulate peer review and catch weaknesses before submission."
