# Philo Lit

Help the user survey existing scholarship, identify debates and gaps, and position their contribution.

## Workflow

### 1. Get the Research Question

If the user provides a topic instead of a question, ask what their argument or thesis is. A literature review without a thesis is just a reading list.

### 2. Build the Literature Map

See the **literature-review** skill for the full protocol. Key points:
- Organize thematically along 3-5 axes, never source-by-source
- Include both supporting and challenging sources
- Flag all bibliographic details for user verification (LLM citations may be fabricated)

### 3. Deliver

Produce a thematic literature synthesis with an explicit gap statement showing where the user's contribution fits.

### 4. Handoff

When the landscape is mapped, suggest: "You can use `/philo-draft` to start writing with a clear argument skeleton."
